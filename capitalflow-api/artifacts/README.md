# Artifacts cục bộ

Thư mục này chứa đầu ra sinh tự động từ các công cụ kiểm thử và chẩn đoán. Các file này không phải mã nguồn hoặc tài liệu chuẩn để commit.

- `load-tests/`: JSON/Markdown theo timestamp từ kiểm thử tải cục bộ hoặc staging.
- Runbook, trạng thái chuẩn và bản tổng kết được duy trì trong `docs/`.
- CI nên lưu artifact cần truy vết trong hệ thống lưu trữ của pipeline thay vì Git.
